# ProtoCarry v0.1.1

This release adds explicit support for empty Protobuf output and replay of v0.1.0 evidence.

## Empty messages

Set `empty_output: "message"` when a successful adapter may return a valid zero-byte message. ProtoCarry decodes that output with the newer schema and compares values and explicit presence as usual. Losing the only nondefault added field produces FAIL; preserving an empty message produces PASS.

The default, `"reject"`, keeps v0.1.0's transport-error behavior. Refusal, nonzero exit, timeout, incomplete input, output truncation, incomplete pipe drain, malformed output and resource limits retain their handling. Adapters must signal errors or refusals explicitly: zero bytes do not reveal whether the result was intentional.

## Evidence compatibility

Replay accepts format `1` bundles produced by `0.1.0` with the legacy reject policy, and format `2` bundles produced by `0.1.1` with their saved policy. Unsupported combinations are rejected before adapter execution.

New evidence uses format `2`, saves the effective output policy and records the immediate replay source producer separately from the current engine. Exact input bytes, artifact hashes and recomputed assertions remain required. Compatibility preserves the saved contract; changes to the application or environment may change the outcome. v0.1.0 cannot replay format `2` bundles.

## Validation and distribution

The [runtime validation](../../validation/protobufjs/README.md) retains the protobuf.js 8.6.1/8.6.2/8.8.0 and official Go v1.36.12 matrix. New controls cover default discard to an empty message, preservation opt-in and a preserving empty-seed roundtrip. Original measurements and v0.1.0 bundles remain available for replay testing.

Release targets remain macOS arm64 and Linux arm64, with standalone binary archives and SHA-256 checksums. The supported schema model and stdin/stdout adapter protocol are unchanged.

See the [README](../../README.md) for setup and the [contract reference](../contract.md) for configuration and replay rules.
