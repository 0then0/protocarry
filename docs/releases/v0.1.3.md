# ProtoCarry v0.1.3

This release adds native binary archives for macOS x64 (Intel) and Linux x64. The CLI behavior, check logic, configuration format, schema scope and evidence format are unchanged.

## Platforms

Archives are now provided for four targets: macOS arm64, macOS x64, Linux arm64 and Linux x64. Each is built, tested and run on a native GitHub runner of that platform, and each has a SHA-256 checksum. The release is published only after all four builds and checksum verifications pass.

Windows is not supported. Adapter timeout and cleanup rely on POSIX process groups, and other operating systems receive an infrastructure outcome before an adapter starts.

## Evidence compatibility

Replay accepts format `2` evidence produced by `0.1.1`, `0.1.2` and `0.1.3`, and format `1` evidence produced by `0.1.0`. Other producer and format combinations are still rejected before adapter execution.

See the [README](../../README.md) for installation and the [contract reference](../contract.md) for configuration and replay rules.
